# Getting Started with the Source Code

1) Install Node.js LTS version.
2) Install neu cli globally - `npm install -g @neutralinojs/neu`.
3) Clone `Chobi` source code from github.
4) Open the folder in your preferred editor and run `neu update` from terminal.
5) The main files ( `index.html`, `styles.css`, `main.js` ) are inside `resources` folder.
